latest - 2026.10.06

Published 2026-10-06. dinit is the init and every other init is gone. The boot runs as parallel dinit services, about 3.3 seconds from firmware to login in QEMU. Wireless is iwd with dhcpcd. scraps update moves an existing install to dinit and keeps its enabled services. See the full release notes.

Tarball

The base system with dinit, iwd, dhcpcd and a full LLVM toolchain. Unpack onto a prepared root, run scraps-strap, then scraps add scraplinux-base, a kernel and a bootloader. There is no installer.

  • scraplinux-tarball.tar.xz (202 MiB) - sha256

No live ISO for this release. The 2026.09.01 one still boots the old init.
